# 用户文档

## 与网站下载目录的关系

本目录是网站用户文档的唯一源目录。不要直接修改
`apps/data_interface/web/downloads/docs/`；修改这里的文档后，在
`apps/data_interface/` 运行：

```powershell
.\publish_web.cmd -Mode Check
```

确认无误后运行 `publish_web.cmd`，脚本会重新生成网站文档下载目录和合集，
再按本机 FTP 配置上传。网站不会从另一份手工复制的文档继续发布。
