# 用户文档

## 与网站下载目录的关系

本目录是网站用户文档的唯一源目录。不要直接修改
`apps/data_interface/web/downloads/docs/`；修改这里的文档后，在
`apps/data_interface/` 运行：

```powershell
.\publish_web.cmd -Mode Check
```

确认无误后运行 `publish_web.cmd`，脚本会重新生成网站文档下载目录和合集，
再按本机 FTP 配置上传。网站不会从另一份手工复制的文档继续发布。

## 最新版本特性与体验升级 (v96)

- ⚡ **D203 主力大单与撤单数据精度升级**：全面提升主力成交价格与金额计算精度，优化大额成交与撤单跟踪的展示明细，数据更精准，毫秒级捕捉微观资金动向。
- 🎯 **D204 逐笔委托标准化对齐**：规范深沪两市委托数据标准，统一订单类型与限价/市价申报标记，多市场策略对接更平滑。
- 📊 **D204 快照分笔成交细节增强**：强化盘口快照中分笔成交的明细信息，完善买卖主动方向与流水序号对应关系，盘口撮合动态更清晰。
- ⏱️ **时间序列与历史查询体验优化**：进一步统一快照与逐笔数据的时间格式与序号标准，大幅提升历史数据检索与量化回溯的一致性与便利性。
- 🚀 **全平台纯绿色单文件交付**：三平台（Windows / macOS / Linux）客户端全面实现纯单文件极简分发，完全免安装、零外部依赖组件，解压即运行，轻量高效。
- 🛡️ **高并发连接与稳定性增强**：进一步提升大并发订阅与复杂网络环境下的自动重连机制，数据推送更稳定、更流畅。
